# Onboarding de novo integrante

**Para quem convida (dono do repositório):**
1. Settings → Collaborators → *Add people* → informe o usuário GitHub.
2. Em Settings → Branches, proteja a `main`: exigir Pull Request e o check `build` do CI.
3. Em Settings → Pages, source = *GitHub Actions*.

**Para quem entra:** siga o [CONTRIBUTING](../CONTRIBUTING.md).
