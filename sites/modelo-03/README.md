# Modelo 03 — Planejado

> Estrutura modular reservada para o terceiro modelo de site do ecossistema.

Este diretório está configurado para receber o terceiro projeto. Ao adicionar um `package.json` com o script `"build"`, o orquestrador `scripts/build-all.mjs` compilará e integrará automaticamente os artefatos em `/dist/modelo-03/` para o GitHub Pages.
