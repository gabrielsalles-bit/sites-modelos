# AutoElite Motors - Modelo de Site para Concessionária

Modelo de site premium e moderno voltado para revendas e lojas de veículos seminovos.

## Tecnologias
- **React 18**
- **Vite**
- **Tailwind CSS**
- **Lucide React** (Ícones modernos)
- **Framer Motion**

## Funcionalidades
- **Showroom e Estoque Completo**: Filtro em tempo real por categoria (SUV, Sedan, Hatch, Picape, Esportivo), busca instantânea por nome/versão e ordenação.
- **Destaques da Semana**: Apresentação VIP de veículos com laudo pericial detalhado.
- **Simulador de Financiamento**: Cálculo de parcelas em tempo real (24x a 60x) com ajuste de entrada em slider.
- **Avaliação de Usado na Troca**: Formulário guiado com envio direto para o WhatsApp da concessionária.
- **Sobre & Contato Integrado**: História da empresa, pilares de vistoria técnica, mapa interativo do Google Maps e formulário de mensagem.
- **Modal de Detalhes & Laudo Cautelar**: Galeria de fotos, itens de série, especificações técnicas e checklist de integridade de 100 itens.

## Como Executar

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento
npm run dev

# Gerar build de produção
npm run build
```
